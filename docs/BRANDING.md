# Apachiy TV — branding assets

> **Status:** placeholders. The current launcher icon, banner, splash icon and
> wordmark are simple PNGs generated by `scripts/generate_brand_assets.py`
> with the literal text "Apachiy" / "A" on a `#0D0D0D` background and `#1E88E5`
> foreground. They are **not final** — replace them with a real logo before
> shipping any production build.

## How to replace the assets

1. Drop a square PNG into the same path with the same name. The Gradle
   build system will pick it up automatically; no manifest changes required.
2. For the adaptive icon (Android 8.0+), the system masks the foreground to a
   circle/squircle/circle-square/...; keep important content inside the inner
   **108dp safe area** of the 432×432 canvas.
3. Re-run `./gradlew :app:assembleFullDebug` to verify the new asset shows up
   on the launcher and the Android TV home screen.

## How to regenerate placeholders

The placeholder PNGs are generated by a Python script. To regenerate after
editing brand text or colors:

```bash
python scripts/generate_brand_assets.py
```

The script reads `scripts/generate_brand_assets.py`. Edit the `BG` / `FG` /
`ACCENT` color constants at the top of the file to change the placeholder
palette.

## Color reference

- **Background** — `#0D0D0D` (off-black, OLED-friendly)
- **Foreground (Apachiy Blue)** — `#1E88E5` (Material Blue 600)
- **Accent (Apachiy Orange)** — `#FF9800` (Material Orange 500)
- **Text on dark** — `#FFFFFF` for primary, `#B0B0B0` for secondary

These match the placeholder PNGs and the `colors.xml` `splash_background` value.
